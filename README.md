A program that writes one fortune cookie message for a software engineer to
`/output/entry.txt`, for the make.fun competition
[Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a).

Run it with Python 3:

```
python3 main.py
```

It writes the fortune below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The fortune is 71 characters, inside the 1 to 120 gate.
